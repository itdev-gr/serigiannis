# 200 επιπλέον tests σε όλο το project — Implementation Plan

**Goal:** +200 διακριτά tests πάνω από τη βάση των 357, ώστε κάθε τομέας του project να έχει αυτοματοποιημένη κάλυψη.

**Architecture:** Τρεις παράλληλοι τομείς, ένα αρχείο ο καθένας, χωρίς επικαλύψεις μεταξύ τους ούτε με τα 12 υπάρχοντα αρχεία tests.

## Global Constraints

- **Καμία αλλαγή παραγωγικού κώδικα.** Μόνο νέα αρχεία tests.
- Αν ένα test αποκαλύψει σφάλμα: καταγράφει την **πραγματική** συμπεριφορά ώστε να περνά, και το ύποπτο αναφέρεται χωριστά.
- Ελληνικές περιγραφές, imports με `@/`, μοτίβο ίδιο με τα υπάρχοντα.
- Components που τραβούν server actions χρειάζονται `vi.mock`, όπως στο `tests/checkout-schema.test.ts`.
- Τέλος: `npx tsc --noEmit`, `npx oxlint`, `npx vitest run`, `npm run build` πράσινα.
